# dad-joke-showdown

[![make.fun · u-mfnakmal-dad-joke-showdown-1d2ce3e5](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5.svg)](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5?utm_source=github&utm_medium=readme&utm_campaign=u-mfnakmal-dad-joke-showdown-1d2ce3e5)

One dad joke, 76 characters: a dad buys memory-foam shoes, and the foam's "memory" turns literal — he can no longer forget a single step he has taken. A house judge compares the jokes two at a time; the biggest groans take the $5 pool (1st $2, 2nd $2, 3rd $1). This program writes that one joke to /output/entry.txt.

Run it: `python3 main.py` (writes /output/entry.txt).
